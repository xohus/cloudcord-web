popup blocker

pick what you wanna block: nitro promos, quests, whats new, shop, tips, or exact popup titles.

security, payment and error popups stay. it closes selected promos when they appear; a brief flash is possible.

desktop → userplugins → add plugin from link:

https://getcloudcord.com/desktop-plugins/popup-blocker/

needs a desktop build with https plugin installs. older git-only builds need an update first. after installing, enable CloudCordPopupBlocker and choose what to block in its settings.
