Installation

  1. Download the Mac build directly on this Mac using Safari. Avoid transferring the installer through WhatsApp.
  2. Choose Apple Silicon for an M-series Mac. Choose Intel for an Intel Mac. Check Apple menu → About This Mac if unsure.
  3. Open the downloaded disk image. If you received a ZIP, extract it first.
  4. Drag CloudCord onto Applications, then eject the disk image.
  5. Quit Discord completely with Command–Q. Open CloudCord from Applications.
  6. Select your installed Discord app, then choose Install / Reinstall.
  7. Open Discord. To remove CloudCord later, quit Discord, reopen the installer and choose Uninstall.

If Apple cannot verify the app

This build is not notarized by Apple. The verification warning is not itself a malware detection, but it is not proof of safety either.

If you trust the download and the Mac’s owner agrees, try opening CloudCord once, then use System Settings → Privacy & Security → Open Anyway and confirm.

Do not disable Gatekeeper. If macOS explicitly reports malware, stop rather than bypassing that warning.

Apple’s instructions

Troubleshooting

“Cannot be opened” after a WhatsApp transfer: download a fresh copy directly in Safari. Open the copy in Applications, not an older mounted disk image.

Discord not found: install Discord first, or choose your existing Discord.app with the installer’s file picker.

Installation failed: quit Discord and confirm your account can modify the selected app. CloudCord keeps the original Discord archive as a backup.

Security scans: scan results apply to one exact file hash. Zero detections do not guarantee safety; engines unable to scan the file give no verdict. A scan does not replace Apple notarization.

For the public beta scanned on October 8, 2026: Apple Silicon: 0/61 detections; Intel: 0/60 detections (one timeout and one failed scan). Unsupported engines are excluded.
