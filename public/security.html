Safety and transparency

Understand CloudCord before you install it.

CloudCord is open-source client customization software for supported Discord clients. It changes the client interface and adds optional features; it is not intended to steal credentials, provide remote access, mine cryptocurrency, encrypt files, or hide unrelated background activity.

Why security tools may show a warning

Modified desktop and mobile packages can look unusual to automated scanners because they patch, inject, sideload, or extend another application. New releases may also have limited reputation data. A warning is a reason to investigate—not automatic proof that a file is malicious or safe.

Confirm that the download came from this official website or the official Xohus repository. Avoid shortened links, reuploads, mirrors, and packages modified by third parties.

What makes the official project verifiable

  • Public source history and release metadata.
  • Platform-specific downloads linked from the canonical CloudCord website.
  • Published changelogs and a live service-status page.
  • A privacy policy describing local data and connected services.
  • A security contact file at /.well-known/security.txt.

Permissions and data

CloudCord needs access related to customizing and running the supported client. It should not require remote desktop control, unrelated financial access, or your device passcode. Core settings are kept locally where practical. Optional synchronization, membership, update, or third-party plugin features may connect to external services; review their descriptions before enabling them.

Plugins have their own risk

A plugin can execute within the modified client and may communicate with services outside CloudCord. Use built-in or reviewed plugins when possible, inspect unfamiliar source, and remove anything that requests credentials or permissions unrelated to its stated purpose. CloudCord cannot certify every third-party plugin.

Discord account considerations

CloudCord is independent and is not affiliated with or endorsed by Discord Inc. Modified clients may conflict with Discord’s Terms of Service. No developer can truthfully guarantee zero account-enforcement risk. Review current Discord rules and consider a secondary account when evaluating modifications.

Protect yourself

  1. Download only from official links.
  2. Keep your operating system and CloudCord release current.
  3. Never paste a Discord token into an unfamiliar website, plugin, or support message.
  4. Use a unique password and multi-factor authentication.
  5. Review plugins before installing or updating them.
  6. Report unexpected network activity, permission prompts, or modified packages.

Report a concern

Report vulnerabilities privately through the official repository security page or the official CloudCord community. Include the affected version, platform, reproduction steps, and impact. Do not access other users’ data or publicly disclose an unresolved issue.
